# 대만 중국어 연습

2027년 2월 대만 여행을 준비하며 쓰는 대만 중국어(臺灣華語) 연습 도구 모음입니다. GitHub Pages로 배포하고, 휴대폰에서 홈 화면에 추가해 앱처럼 쓸 수 있습니다(PWA).

- `routine/`: 오늘의 성조 루틴. 성조 짝 듣기 퀴즈(기본 2↔3성) → 성조 거울로 한 음절 말하기 → 두 음절 단어(성조 변화 규칙 포함)를 단계별 5분 타이머로 이끌고, 하루 기록을 '기록 복사'로 꺼낼 수 있습니다. 듣기 퀴즈는 같은 음절을 여러 성조로 읽은 128개 음성(`routine/clips.js`, Polly Zhiyu 신경망 음성, 3성은 대만식으로 낮게 보정, 남녀 두 목소리)을 쓰고, 말하기 단계는 `tone/`을 그대로 띄웁니다.
- `numbers/`: 가격 듣기. '八十五塊'처럼 가게에서 말하는 1~999元 가격을 듣고 숫자로 입력하거나, 낸 돈(100/500/1000元)에서 거스름돈을 계산해 입력합니다. 음성은 Polly Zhiyu로 만든 999개 클립을 백 단위 묶음 10개(`numbers/audio/`)로 나눠 필요할 때만 받고, 틀린 가격은 세 문제마다 다시 나옵니다. '기록 복사'로 유형별 정답률을 꺼낼 수 있습니다.
- `tone/`: 성조 거울. 마이크로 말하면 음높이 곡선을 목표 성조 모양과 겹쳐 보여 주고 1~4성을 대략 판정합니다. 진도는 브라우저에 저장되고 '기록 복사'로 꺼낼 수 있습니다.

듣기 음성은 Amazon Polly의 Zhiyu 음성(표준 중국어)으로 만들어 페이지에 넣었습니다.
