② 직접 소리 내기

  • 2성: “응?” 하고 되묻듯 쭉 올려요.
  • ▶ 듣기 → ● 녹음 순서로, 2성·3성 글자를 번갈아 해 보세요. 직접 내 본 소리는 귀로도 더 잘 구분돼요.

③ 두 글자 단어

실제 대화에서 성조는 거의 단어로 붙어서 나와요. 이 규칙을 의식하면서 듣고 따라 말해 보세요.

  • 3성 + 3성 → 2성 + 3성: 你好 nǐ hǎo는 ní hǎo로, 很好도 hén hǎo로 읽어요.
  • 3성 + 다른 성조: 앞 3성은 낮게만 깔고 끝을 올리지 않아요. 好吃, 老師
  • 不 + 4성 → 2성: 不要 bù yào는 bú yào로 읽어요.

你好 → 很好 → 好吃 → 不要 순서로 시작해서 나머지 단어로 넓혀 가세요.
